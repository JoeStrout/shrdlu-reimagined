Talking to the robot

      
Type in the console on the left and press Return.  Try these in order:

      
    
        
  • Pick up a big red block.
    • 
        
  • Find a block which is taller than the one you are holding and put it into the box.
    • 
        
  • What does the box contain?
    • 
        
  • Why did you pick up the blue block?
    • 
        
  • Why?
    • 
        
  • How many blocks are not in the box?
    • 
        
  • Is there a large block behind a pyramid?
    • 
      

      
You can also teach it new words (“A steeple is a stack which contains two green cubes and a pyramid.”) and ask about what it did and why.

    


    

      
Mouse and keys

      
    
        
  • Click a block or pyramid to select it; then you can call it “this”.
    • 
        
  • While the hand holds something, click to put it down there (Shift-click to drop it even where it won't balance).
    • 
        
  • Drag (left or right button) to turn the view; scroll to zoom.
    • 
        
  • Over the console, the wheel scrolls the transcript.  ↑/↓ recall earlier lines; Esc clears the line.
    • 
      

      
Under the hood

      
    
        
  • /icl shows each sentence's meaning in ICL, the robot's internal language.
    • 
        
  • A line starting with : is typed in ICL directly: : x1 = a pyramid; Ask color x1
    • 
        
  • /scene playground loads a different world; /scene winograd brings back the original.

What is this?

  
SHRDLU was Terry Winograd's landmark program at MIT: you typed to it in English, and it moved blocks, answered questions, learned new words, and explained its reasons.  SHRDLU Reimagined is not a port of that program but a clean-sheet successor built on the same ideas.  Everything is hand-written: the parser, the grammar, the reasoning, the planner, and the replies are explicit code you can read.  No machine learning or LLMs are used.  The physics, too, is a few simple, predictable rules, so the robot can reason reliably about its world.

  
It's written in MiniScript and runs on raylib-miniscript, both on the desktop and here in the browser.  The source is meant to be read: see the repository on GitHub.
