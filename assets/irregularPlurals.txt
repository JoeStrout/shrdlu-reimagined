# Nouns whose plurals don't follow the usual rules (see icl.singularize
# and icl.pluralize).  One per line: the singular, then the plural.
#
# The usual rules: add -s ("block" -> "blocks"); add -es after s, x, ch or
# sh ("box" -> "boxes"); and change a y after a consonant to -ies ("body"
# -> "bodies").  Anything else goes here, including:
#   - words that look as if they follow the rules but don't ("pie" ->
#     "pies" is regular, but would otherwise be read back as "py")
#   - words whose singular ends in s ("bus"), which would otherwise be read
#     as plurals
#   - words that are the same in both ("sheep")
# A word may have two plurals ("die": "dice", or "dies" for the tool); the
# first one listed is the one the robot uses.
#
# Lines starting with # are comments.
